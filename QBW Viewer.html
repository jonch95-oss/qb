Decoded with OpenQBW, an open-source, reverse-engineered, read-only parser. Amounts marked * include values OpenQBW cannot decode yet and are left out of totals, so totals can be lower than QuickBooks shows.

Names are recovered from the readable text stored in each record. OpenQBW does not label individual fields yet, so the first text in a record is shown as the name and the rest (address, phone, email, notes…) as details.
